# 数学练习稿工作流

当前用户明确要求优先。默认完整保留原稿的题目、讲解、条件、选项、图表、公式、原有填空线及顺序；不添加答案或自行编写的总结。原稿模糊或自相矛盾时保留并标明，不猜测。

## 1. 规划与准备

1. 保留原 PDF、完整 MinerU 原始 DOCX 和教师样例；计算源文件哈希，核实 PDF 实际页数。对现有 Word 的局部修复按 [基准处理](TROUBLESHOOTING.md#baseline)。
2. 按源页登记章节、题号、题干锚点、各小问、选项、公式、表格、图片和图注；记录跨源页题及经目视确认的空白页。把每项映射到 Word，清单不能代替阅读。
3. 先确定每道完整题组的边界及每个独立小问的答题空间，预见数列对齐、表格、并列选项与图片尺寸；参见 [问题索引](../SKILL.md#问题索引)。题组包括题号、题干、所有小问、选项、公式、表格、图、图注和答题空间。
4. 使用用户选定的版式和编号。若要求普通数字编号，使用文字题号，不使用 Word 自动编号；MinerU 若导出为自动列表，先记录显示编号及重启位置，再只对目标列表用 Word 的 ConvertNumbersToText 转为文字，复核题号、小问和公式节点。讲标题可居中；页首题号和正文顶格，题内小问可有层级缩进。
5. 准备工作稿并做结构规划及 **真实 Word 分页预检**，通过后才编辑题目内容。自动标准路线见 [MinerU 流程](MINERU_FIRST.md)；用户禁止段落分页设置时走本文件的 Enter 分支。

## 2. 内容与图片

可编辑文字和公式优先使用 Word 文本与 OfficeMath；编辑含公式的段落时只改相关文本 run，不能用 `paragraph.text = ...` 覆盖整段并丢失公式 XML。复杂题图可从原 PDF 高清裁切并靠近所属题，保留图注；教师样例不能作为内容来源。

首次构建时由 `scripts/image_sizing.py` 在题目规划之前应用图片规则，参数在 `references/style_profile.json`：

- 同一讲的现有小图以 `0 < 宽度 ≤ 6.0 cm` 为参照，取宽度中位数；超过 6.0 cm 的图片缩到该中位数，小图不放大。
- 同讲没有参照图则用全文小图中位数；全文也没有则用 4.05 cm。只改 Word 显示大小，保持宽高比和原始图片数据。
- 并列选项须按原稿作为一组规划；如果多个选项要求等大，首次建模时统一方格或等比尺寸。后来用户指定修复不一致图片时，按源稿修复受影响的一组，并重新检查相关分页；不要反复全稿缩图。

## 3. 题组、答题空间与分页

- 一道完整题及全部小问、图表、图注和对应答题空间在同一页；页尾空间不足时整组移到下一页。每页正文区域从题目或所属标题开始，题号顶格。
- 每道独立题、每个独立小问都预留答题空间，大题预算按各小问累加。默认每项：简单选择/填空/短答 2 行，普通题 3 行，计算或解方程 4 行，长应用题或图表推理 5 行，证明或多步推导 6 行；按难度和用户要求调整。
- 每一行答题空间是一个真正的 Enter 空段落；不得用 Shift+Enter、下划线、边框、表格、空格、制表符、形状、文本框或段前段后间距伪造。题干自带的括号和填空线属于源内容，不能替代过程空间。局部修复时保留已有答题空段，不做全局空白清理。
- 用户未禁止时，默认规划器可用 keep-together/keep-with-next 让题组保持同页；这些属性不产生答题空间。不因源 PDF 换页而插入手动分页符。
- 如果整题连最低合理答题空间都无法放入一页，先按原稿检查图表尺寸，收紧题内冗余、适度调整字号且不低于 9 pt；仍放不下时报告具体题目，不能交付拆页题。

### 用户禁止段落分页或换行设置时

准备工作稿时在 prepare 或 build 加 `--pagination-mode enter`；已有工作稿需要重新规划时运行：

~~~powershell
$py = 'D:\我的python\python3.12\python.exe'
& $py scripts\question_layout.py apply --docx 'job1\working.docx' --profile $profile --pagination-mode enter
& $py scripts\question_layout.py check --docx 'job1\working.docx' --profile $profile --pagination-mode enter
~~~

该模式在副本中清除段落及继承样式的换行/分页属性，保留既有答题空段，按小问补充真实 Enter 空段；通过 Word 实际分页，只用新空段把整题及所属标题移页，再检查禁用属性、页首与题组起止页。重跑只重建程序插入的分页空段。原稿中的手动换行、浮动图或多分节等不支持的结构需先人工整理；题目超过一页或无法确保页首无空段时停止并保留原稿。核对自动识别的题组数量、图表归属与源稿一致，内容或题组改变后重新规划并检查。

## 4. 最终核对与交付

用 Microsoft Word 实际渲染，按源页清单逐页对照完整内容、数字、公式、选项、图表及图注，并检查每题与答题空间同页、页首顶格。只复看改动页；可对哈希完全相同的已检查页面沿用实际查看过的记录。自动计数和 OCR 置信度只用于定位疑点。

手动填写真实核对结果与最终 DOCX 哈希；修改使相关旧审核记录失效。自动审计按工作区记录的分页模式检查实际交付稿并要求 accepted；源页记录恰好覆盖每页一次且不得虚填。若用户有明确交付范围、文件名和位置，以其要求为准；否则保留原 PDF、同原名 DOCX、Word 预览 PDF（`_Word版` 后缀）及验收报告。交付前保护已有文件，复制后核对候选稿、交付稿和原 PDF 哈希。
